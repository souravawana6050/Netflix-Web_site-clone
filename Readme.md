# Netflix Website Clone

A responsive Netflix-inspired website clone built to practice front-end web development and recreate the look and feel of a modern streaming platform.

## 🚀 Features

* Responsive design
* Netflix-style homepage
* Navigation bar
* Movie and TV show sections
* Hero/banner section
* Interactive UI
* Clean and modern layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Overview

This project is a front-end clone inspired by Netflix. It was created to improve my skills in HTML, CSS, JavaScript, responsive design, and user interface development.
